# RupiahRapi — website

Situs publik aplikasi RupiahRapi: halaman utama, dukungan, dan
[kebijakan privasi](https://debu-distric10.github.io/rupiahrapi-web/privasi.html).

- Next.js (App Router) + TypeScript, **ekspor statis** (`output: "export"`).
- Tanpa analitik, pelacak, atau font dari server lain.
- Terbit otomatis ke GitHub Pages lewat `.github/workflows/deploy.yml`.

```
npm install
npm run dev     # http://localhost:3000
npm run build   # hasil di out/
```
